# CONTRIBUTING - DT15 Cipher Tool

## 1. Quy tac lam viec

- Moi thanh vien lam viec tren mot nhanh rieng.
- Ten nhanh theo mau ten/chuc-nang.
- Khong push truc tiep len main khi quy trinh bao ve nhanh da duoc bat.

## 2. Quy tac commit

- feat(...): them tinh nang.
- fix(...): sua loi.
- test(...): them hoac cap nhat kiem thu.
- docs(...): cap nhat tai lieu.
- Moi commit nen tap trung vao mot cong viec.

## 3. Pull Request

- Moi PR chi xu ly mot cong viec nho.
- Moi PR can it nhat 1 nguoi review.
- Han review thong thuong: 24 gio.
- PR gan nhan blocker: han review 12 gio.
- Chi Vu merge vao main.

## 4. Quan ly file

- Moi file co mot nguoi phu trach chinh.
- Neu can sua file cua nguoi khac, hay trao doi
  voi nguoi phu trach truoc.

## 5. Quyet dinh ky thuat

- De xuat thay doi ky thuat ghi [DE XUAT].
- Neu sau 24 gio khong co y kien phan doi,
  ghi quyet dinh da thong nhat vao DECISIONS.md.
